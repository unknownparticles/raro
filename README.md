# 🔮 AI Tarot Analysis (AI 塔罗测算)

一个不仅拥有神秘美学设计，更融合了现代 AI 智慧的塔罗牌测算应用。

> **当前版本特性**：沉浸式“秘境琉璃”主题、真实物理交互卡牌、DeepSeek AI 深度解牌、本地历史记录存储。

## ✨ 主要功能

*   **🌌 秘境琉璃 UI (Mystical Glass Theme)**
    *   深邃的星空背景，搭配动态流光效果。
    *   全磨砂玻璃质感界面，辅以金边流光，营造高端神秘氛围。
    *   完美适配移动端与桌面端，丝滑般的视觉体验。

*   **🎴 沉浸式互动牌阵**
    *   **扇形洗牌**：支持鼠标/触摸拖拽旋转牌组，还原真实洗牌手感。
    *   **多种经典牌阵**：支持时间之流三张、抉择指引三张、关系洞察五张、事业路径五张。
    *   **直觉抽牌**：用户凭借直觉完成二次确认抽牌，再将卡牌放入对应牌位。
    *   **飞牌动画**：卡牌从牌组飞入牌阵的流畅动画效果。

*   **🧠 AI 深度解牌**
    *   支持 DeepSeek、GLM、Kimi 等 OpenAI 兼容接口。
    *   根据抽出的牌面（正位/逆位）及牌阵位置，生成更贴合牌位职责的解读。
    *   **Markdown 渲染**：解读结果支持富文本格式（标题、加粗、引用），阅读体验极佳。

*   **📜 历史记录回溯**
    *   自动保存每一次的测算结果到本地浏览器。
    *   侧边栏抽屉式设计，随时查看过往的每一次启示。

*   **🔐 安全与隐私**
    *   API Key 仅存储在用户本地 `localStorage`，不经过第三方服务器。
    *   集成 Auth0 身份验证（可选功能）。

## 🛠️ 技术栈

*   **前端核心**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
*   **AI 接口**: DeepSeek API (OpenAI Compatible)
*   **工具库**: 
    *   `marked.js` (Markdown 解析)
    *   `Auth0 SDK` (身份验证)
*   **无需构建**: 纯静态页面架构，开箱即用，无需 `npm install`。

## 🚀 快速开始

### 1. 克隆项目
```bash
git clone https://github.com/unknownparticles/raro.git
cd raro
```

### 2. 运行项目
由于项目包含 ES Modules 和 API 请求，建议使用本地服务器运行（避免 CORS 问题）。

如果你安装了 Python:
```bash
# Python 3
python -m http.server 8000
```
然后浏览器访问 `http://localhost:8000`

### 3. 配置 AI 模型
1. 点击页面顶部的 **⚙️ 设置** 按钮。
2. 选择 AI Provider，并输入对应 API Key。
3. 保存后即可开始测算。
